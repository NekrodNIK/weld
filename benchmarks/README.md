# Nginx static link benchmark

Сравнение `mold` vs `ld.bfd` на статической линковке nginx (118 .o файлов, 11MB бинарник).

## Результаты

| Конфиг | Time | vs ld | Scaling |
|--------|------|-------|---------|
| `ld` | 226.5 ms | 1.00x | — |
| `mold-1t` | 90.2 ms | 2.51x | 1.00x |
| `mold-2t` | 60.6 ms | 3.74x | 1.49x |
| `mold-4t` | 48.4 ms | 4.68x | 1.86x |
| **`mold-8t`** | **46.0 ms** | **4.93x** | **1.96x** |
| `mold-16t` | 51.8 ms | 4.37x | 1.74x |

**Scaling есть**: 1t → 8t даёт ~2x ускорение. Выше 8 тредов оверхед перевешивает для 10MB бинарника. Для более крупного проекта (nginx с SSL/PCRE/Zlib) scaling будет заметнее.

## Использование

```bash
# Собрать объектники
./build.sh

# Линковка
./link.sh ld        # ссылка ld.bfd
./link.sh mold 4    # ссылка mold с 4 тредами

# Бенчмарк
./benchmark.sh      # hyperfine по всем конфигам
```
